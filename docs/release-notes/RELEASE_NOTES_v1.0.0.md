## 子午流注·经络全息钟 v1.0.0 — 首个正式版 🎉

一个 Windows 3D 动态桌面壁纸：全息人体缓缓旋转，十二经络按**北京时间**十二时辰依次流注点亮，粒子星环组成表盘。

### ✨ 亮点
- 全息 3D 人体，360° 旋转（可选 90/60/30 秒一圈，或停止）
- 十二经络 3D 循行；当令经络金光流注，背面可 X 光透视
- 3.2 万粒子星环表盘，玻璃拟态信息面板，每个时辰 5 宜 5 忌
- 嵌在桌面图标之后（支持 Win10、Win11、24H2），有兼容模式兜底
- 全屏程序时自动暂停，用电池时降帧，高/中/低三档画质，另有安全模式
- 单文件自包含 exe，完全离线

**系统要求**：Windows 10 1809+ / 11 x64，需要 WebView2 Runtime（系统通常已自带）。程序未做代码签名，SmartScreen 提示时点“更多信息 → 仍要运行”。

**如有黑斑或闪烁**：托盘 → 画质 → 中，或 托盘 → 高级 → 安全模式。

### English
First stable release of a 3D live wallpaper for Windows 10/11. A holographic body slowly rotates while the active meridian of the current Chinese double-hour, on Beijing time (UTC+8), flows with golden particles. The dial is a particle star-ring.

Download the `win-x64` zip, extract it and run the exe; the WebView2 Runtime is required. The `web` zip works with Lively Wallpaper. The exe is unsigned, so SmartScreen may warn on first run. Health content is not medical advice.
