Fallback: Lively Wallpaper (https://www.rocksdanister.com/lively/ , also in Microsoft Store)
1. Install Lively Wallpaper.
2. Lively -> "+" Add Wallpaper -> select  web\index.html  (or drag a zip of the web folder; LivelyInfo.json is included).
3. Click the wallpaper -> "Set as Wallpaper".
Quality: append ?q=mid or ?q=low to the page URL. Bottom 48px is reserved for the taskbar by default (?ib=0 to disable).
Do not run ZiwuMeridianClock.exe at the same time.
