子午流注·经络全息钟　使用说明（Windows 10 / 11，64 位）
=========================================================

一、如何运行
  1. 把压缩包【完整解压】到一个固定的文件夹，例如 D:\Apps\ZiwuMeridianClock\。
     不要直接在压缩包里双击运行。ZiwuMeridianClock.exe 必须和 web 文件夹放在同一目录。
  2. 双击 ZiwuMeridianClock.exe。几秒后，桌面壁纸会变成“全息人体 + 粒子星环十二时辰钟”。
     · 画面在桌面图标的后面，图标照常可以点击、拖动。
     · 时间固定按北京时间（UTC+8）计算，与系统时区无关。
  3. 任务栏右下角会出现太极图标（托盘）。如果看不到，请点“^”展开隐藏的图标。
  4. 需要 Microsoft Edge WebView2 运行时（Windows 11 和大多数 Windows 10 已自带）。
     如果缺少，程序会弹窗提示，并打开下载页：
     https://go.microsoft.com/fwlink/p/?LinkId=2124703
     安装后重新运行即可。

二、托盘菜单（右键太极图标）
  · 显示 / 隐藏：临时隐藏动态壁纸。隐藏后停止渲染，不占用显卡；再点一次恢复。双击托盘图标效果相同。
  · 开机自启：打勾后，登录 Windows 时自动启动。
    （写入 HKCU\Software\Microsoft\Windows\CurrentVersion\Run，不需要管理员权限。）
  · 画质：
      高 — 30 帧，完整粒子，适合独立显卡或较新的核显；
      中 — 24 帧，约 60% 粒子，较低分辨率渲染；
      低 — 15 帧，约 35% 粒子，适合笔记本、省电。
  · 旋转速度：慢（90 秒一圈）/ 中（60 秒一圈，默认）/ 快（30 秒一圈）/ 停止（停在正面）。
    人体 360° 缓慢转动。转到背面时，当令经络会透过身体以较淡的金光显示，便于跟随路线。
  · 高级：
      在所有显示器显示 — 默认只在主显示器显示；
      全屏程序/游戏时暂停 — 默认开启，前台全屏时自动暂停渲染；
      显示模式：
        “桌面壁纸层（推荐）”— 画面嵌在桌面图标之后；
        “兼容模式（置底窗口）”— 嵌入失败时使用。画面会盖住桌面图标，但鼠标会穿透到桌面；
      重新嵌入桌面 — 画面异常时手动刷新；
      打开日志目录 — 查看 log.txt。
  · 退出：关闭程序并恢复原来的桌面壁纸。

三、自动行为
  · 只能运行一个实例，重复打开会提示“已在运行”。
  · 资源管理器（Explorer）重启、分辨率或缩放改变、插拔显示器、休眠唤醒后，会自动重新嵌入。
  · 前台有全屏程序或游戏时暂停渲染。
  · 电池供电时帧率降到 20，开启“省电模式”时降到 10。
  · 布局会自动适配分辨率（1366×768、1920×1080、2K、4K 高 DPI、带鱼屏）：
    表盘和人体在右侧约 60% 的区域，信息面板在最右，左侧留空，不会被任务栏遮挡。

四、卸载
  1. 托盘菜单先取消“开机自启”（或保持勾选，第 3 步会一并清理），然后点“退出”。
  2. 删除程序所在文件夹。
  3. 可选：删除 %LOCALAPPDATA%\ZiwuMeridianClock（里面是设置、日志和 WebView2 缓存）。
     如果之前开了开机自启又没有取消，可在“任务管理器 → 启动应用”里禁用，
     或删除注册表 HKCU\Software\Microsoft\Windows\CurrentVersion\Run\ZiwuMeridianClock。
  本程序不写系统目录，不安装服务。

五、常见问题
  Q：双击后出现“Windows 已保护你的电脑”（SmartScreen）？
  A：这是因为程序没有购买代码签名证书，并非病毒。点“更多信息”→“仍要运行”即可。

  Q：杀毒软件报毒或拦截？
  A：动态壁纸需要把窗口放到桌面层（SetParent 到 WorkerW），并写入开机自启注册表项，
     部分杀毒软件会误报。请把程序文件夹加入信任/白名单。

  Q：桌面没有变化，或者黑屏？
  A：① 右键托盘 → 高级 → 重新嵌入桌面；
     ② 仍不行就切换到“兼容模式（置底窗口）”；
     ③ 查看日志 %LOCALAPPDATA%\ZiwuMeridianClock\log.txt，
       里面有“嵌入成功: ClassicWorkerW/Progman24H2 …”或错误信息。
     Windows 11 24H2 及以后的桌面结构有变化，程序已经做了适配。
     个别机器如果仍然不行，请用第六节的 Lively 方案。

  Q：人体上出现闪烁的小黑斑？
  A：v5 已修复已知原因（深度预写与全息表面 z-fighting、MSAA 兼容性）。若个别显卡仍有：
     ① 画质改为“中”（关闭 MSAA，改用 FXAA）；
     ② 右键托盘 → 高级 → 安全模式（关闭褶皱暗化、MSAA、Bloom）。若安全模式下黑斑消失，请告知是哪一步起效；
     ③ 也可编辑 %LOCALAPPDATA%\ZiwuMeridianClock\settings.json 的 "ExtraParams"（如 "q=mid" 或 "safe=1"），重启程序。
     Lively 用户：地址改为 index.html?safe=1。

  Q：卡顿、风扇响、耗电？
  A：画质改为“中”或“低”。全屏游戏时程序会自动暂停。

  Q：只想在副屏显示 / 多屏显示？
  A：高级 → 在所有显示器显示（每个显示器各显示一份）。

  Q：时间不对？
  A：程序固定显示北京时间，按系统 UTC 时间换算。请确认 Windows 的时间已经同步。

六、备用方案：用 Lively Wallpaper 加载（如果 exe 有问题）
  Lively Wallpaper 是免费开源的动态壁纸软件，可从 Microsoft Store 搜索“Lively Wallpaper”安装。
  1. 安装并打开 Lively。
  2. 点左上角“+”（添加壁纸）→“浏览/选择文件”，选择本压缩包里的 web\index.html。
     也可以把整个 web 文件夹压缩成 zip 后拖进 Lively，里面已附带 LivelyInfo.json。
  3. 在壁纸库里点它，选择“设为壁纸”。
  · Lively 模式下画面底部默认给任务栏留 48 像素。
  · 若想调整画质，可在 Lively 中把 index.html 的地址参数改为
    index.html?q=mid 或 index.html?q=low。
  · 用 Lively 时不需要运行 ZiwuMeridianClock.exe，两者不要同时使用。
  · 也可以直接用 Edge/Chrome 打开 web\index.html 预览。
    浏览器直接打开本地文件可能因安全限制无法加载，建议用 Lively。

七、技术信息
  · 程序：C# .NET 8 WinForms + Microsoft WebView2，自包含单文件，不需要另装 .NET。
  · 网页：three.js（GPU 粒子 + Bloom），全部资源和字体都在本地，不需要联网。
  · 设置：%LOCALAPPDATA%\ZiwuMeridianClock\settings.json
  · 日志：%LOCALAPPDATA%\ZiwuMeridianClock\log.txt
